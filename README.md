# Operator OS

Canonical business-neutral Worker and Operations PWA extracted from the proven Focus Lab implementation. Business selection is typed and deployment-time; data, security bindings, Workers, and Durable Objects remain physically isolated.

Focus staging uses `deployments/focus-lab/`. Moses staging files are intentionally non-deployable templates until its Cloudflare resource identifiers and Access application are approved and provisioned.

No runtime multitenancy or tenant identifier is used.
